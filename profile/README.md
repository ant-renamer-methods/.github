# Ant Renamer - Preview Every New Name

Ant Renamer is a batch renamer for files you may rename. Methods, tags, and pairs of text are rules you can read. The preview is the product. Until you apply, the originals keep their names.

---

## Product Snapshot

The window lists the current name and the name the rule would write. A counter, a date, or a piece of the old name can be part of the pattern. A pattern can also erase the only part that told you what the file was. That is why the list is there.

Start with a handful of files you copied on purpose. A shoot of hundreds can wait until a dozen names look right. System folders stay out even if one file inside them looks badly named. Those names are often what an installer expects.

## Highlights

- A preview column of old name and new name before any write
- Methods you can read: text, numbers, dates, and case
- A small first batch instead of an entire disk
- A stop when two files would share one name
- Your folder, not a Windows path
- The original directory left intact when you work on a copy

## Live Production

Use it when a card of photos needs a prefix and a counter, or when scans need page numbers. Copy the folder, point Ant Renamer at the copy, and read the list. If line one is fine and line forty is not, fix the rule. Do not apply.

After a good apply, open the copy in Explorer and check a few names against the preview you remember. Only then consider replacing the originals. If a program can no longer find a file, the old name was part of how it worked. Put that name back from the folder you did not touch.

---

## Preview Rules

A method that strips too much will make fifty files look the same. Add a counter before you apply. Tags taken from the file are only as good as the tag. If the tag is empty, the new name will be empty in that part. Look at those rows. A script or a regular expression you do not understand is not a first rule. Use a prefix you can say out loud.

---

## Where Undo Stops

Renaming the copy can be thrown away by deleting the copy. Renaming the only folder cannot. Moving files in the same pass makes the way back harder. Do the rename first, on the copy, and move later if you still want to. Do not mix this hour with a cleanup tool that deletes by its own rules.

---

## Setup Path

Prerequisites: A copied folder small enough that you can read every new name.

1. Install Ant Renamer and add the copied folder.
2. Add one rule, such as a short prefix and a counter.
3. Read the whole preview. Fix duplicates before you continue.
4. Apply to the copy only.
5. Check Explorer. Keep the original folder until the names are right.

## Who Benefits

Ant Renamer fits a photo folder, a set of scans, or downloads you saved and may rename. It does not fit C:\Windows, a shared profile that is not yours, or a hurry that skips the preview.

---

## Fixes

Two files would share a name: do not apply, add a counter. The preview looks right only at the top: read the rest. You renamed the only copy: restore from backup, and do not run another rule until you have one. A program lost its file: the old name mattered, put it back from the folder you kept.
